# ScienceNIR — Telegram + OpenAI

Бұл нұсқа пайдаланушының бұрыннан бар 8 Telegram мәзірін сақтап, олардың бәріне нақты ЖИ жауаптарын қосады.

## 1) Қауіпсіздік (МАҢЫЗДЫ)

Бұрынғы файлдарда токендер ашық жазылған. Оларды міндетті түрде ауыстырыңыз:

- Telegram: @BotFather → `/revoke` → ботыңызды таңдаңыз → жаңа токен алыңыз.
- OpenAI: https://platform.openai.com/api-keys → бұрынғы кілтті өшіріп, жаңасын жасаңыз.
- Токендер мен кілттерді чатқа, скриншотқа және GitHub-қа салмаңыз.

## 2) Файлдарды орналастыру

Өзіңіздің бұрынғы жоба папкаңыздағы `main.py`, `ai_assistant.py`, `test_ai.py` файлдарын сақтық көшірмеге көшіріңіз, содан кейін осы нұсқалармен ауыстырыңыз.

`.env.example` файлының атын **`.env`** деп өзгертіп, `OPENAI_API_KEY` пен `TELEGRAM_BOT_TOKEN` мәндерін толтырыңыз.

## 3) Орнату (Windows PowerShell немесе CMD)

```powershell
py -m pip install -r requirements.txt
```

## 4) Алдымен ЖИ-ді тексеру

```powershell
py test_ai.py
```

Егер API дұрыс болса, ЖИ 3 ғылыми тақырып ұсынады. `401` — жарамсыз кілт; `429` — баланс/лимит мәселесі; модель қатесі болса `.env` ішіндегі `OPENAI_MODEL` параметрін тексеріңіз. API қолдану ChatGPT жазылымынан бөлек төленеді.

## 5) Telegram-ботты іске қосу

Бұрынғы іске қосылған ботты терминалда **Ctrl+C** арқылы тоқтатыңыз.

```powershell
py main.py
```

Telegram-да `/start` жіберіңіз, кез келген мәзірді таңдаңыз, кейін сұрақ жазыңыз.

## Мүмкіндіктер және шектеулер

- 8 мәзірдің бәріне ЖИ жауап береді. Сұрақтан бұрын мәзір таңдалса, тапсырма соған сай беріледі.
- Әдебиеттер туралы көмек береді, бірақ нақты интернет іздеу функциясы бұл нұсқада **қосылмаған**.
- PDF құжаттарды өңдеу бұл нұсқада **қосылмаған**; әзірге мәтіндік сұрақтар.
- ЖИ жауаптары міндетті түрде тексерілуі керек.
- Компьютердегі бағдарлама жұмыс істеп тұрғанда ғана бот жауап береді.
